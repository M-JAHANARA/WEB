# سامانه نوبت‌دهی آرایشگاه

پروژه فارسی و راست‌چین برای رزرو آنلاین مشتریان و مدیریت نوبت‌ها، با **HTML، CSS، JavaScript، PHP و MySQL**؛ مناسب اجرا در XAMPP.

## امکانات

- نمایش خدمات، توضیحات، قیمت و مدت هر خدمت از پایگاه داده
- انتخاب تاریخ و مشاهده زمان‌های واقعاً آزاد
- ثبت نوبت با نام و شماره موبایل و تولید کد پیگیری
- نگهداری نوبت جدید در وضعیت «در انتظار تأیید»
- جلوگیری از رزرو هم‌زمان و تداخل بازه‌های زمانی با قفل روزانه MySQL و بررسی سمت سرور
- پنل مدیریت دارای ورود، هش گذرواژه، توکن CSRF، محدودسازی تلاش‌های ناموفق، آمار، جست‌وجو، فیلتر تاریخ و وضعیت
- تأیید، لغو و ثبت پایان خدمت؛ ذخیره وضعیت در MySQL
- اتصال قابل تنظیم پیامک تأیید و لغو با Kavenegar؛ در صورت تنظیم‌نشدن API، وضعیت نوبت ذخیره می‌شود و پنل هشدار می‌دهد
- محل درج نام سازنده `M.JAHANARA` و Gmail در پنل مدیریت
- رابط کاربری واکنش‌گرا، فارسی و RTL با تم زغالی و سبز مریم‌گلی

## نصب با XAMPP

1. پوشه `barber-booking` را در مسیر `C:\xampp\htdocs\` کپی کنید.
2. کنترل‌پنل XAMPP را باز کرده و **Apache** و **MySQL** را روشن کنید.
3. وارد `http://localhost/phpmyadmin` شوید؛ گزینه Import را انتخاب و فایل `database/schema.sql` را اجرا کنید. این فایل دیتابیس `barber_booking`، جدول‌ها و چند خدمت نمونه را می‌سازد.
4. فایل `app/config.php` را باز کنید و `DB_HOST`، `DB_NAME`، `DB_USER` و `DB_PASS` را با تنظیمات MySQL خود هماهنگ کنید. در نصب پیش‌فرض XAMPP معمولاً کاربر `root` و گذرواژه خالی است.
5. برای ساخت اولین مدیر وارد `http://localhost/barber-booking/setup.php` شوید. نام کاربری و یک گذرواژه قوی (حداقل ۱۰ کاراکتر) بسازید. این صفحه پس از ایجاد اولین حساب اجازه ساخت حساب دیگری نمی‌دهد.
6. صفحه مشتری: `http://localhost/barber-booking/`
7. پنل مدیریت: `http://localhost/barber-booking/admin/login.php`

## تنظیم نام آرایشگاه و راه ارتباطی سازنده

در `app/config.php` این مقادیر را ویرایش کنید:

- `SHOP_NAME`: نام تجاری آرایشگاه؛ نمونه فعلی «آرایشگاه» صرفاً مقدار پیش‌فرض است.
- `SHOP_TAGLINE`: جمله کوتاه زیر نام آرایشگاه.
- `SHOP_PHONE`: شماره تماس آرایشگاه (فعلاً در رابط کاربری استفاده نشده است).
- `DEVELOPER_NAME`: نام سازنده که پیش‌فرض آن `M.JAHANARA` است.
- `DEVELOPER_EMAIL`: مقدار `YOUR_EMAIL@gmail.com` را با آدرس Gmail واقعی خودت عوض کن تا لینک تماس پنل کار کند.
- `APP_TIMEZONE`: منطقه زمانی کسب‌وکار؛ پیش‌فرض `Asia/Tehran` است. برای نمونه اگر کسب‌وکار در باکو باشد، می‌توان آن را به `Asia/Baku` تغییر داد.
- `OPENING_TIME` و `CLOSING_TIME`: ساعات کار روزانه.
- `BOOKING_DAYS_AHEAD`: چند روز آینده قابل رزرو باشد.
- `SLOT_INTERVAL_MINUTES`: فاصله شروع گزینه‌های زمانی؛ مدت خدمت همچنان مبنای کنترل تداخل است.

## فعال‌کردن پیامک واقعی

ارسال پیامک تأیید یا لغو پس از تغییر وضعیت در پنل انجام می‌شود. در `app/config.php`، مقدار `KAVENEGAR_API_KEY` را با کلید API معتبر سرویس Kavenegar جایگزین کن و در صورت نیاز `KAVENEGAR_SENDER` را تنظیم کن. افزونه PHP cURL باید فعال باشد. برای استفاده واقعی از سرویس، اعتبار حساب و مجازبودن خط ارسال نیز باید برقرار باشد.

اگر API Key خالی باشد، **پیامک واقعی ارسال نمی‌شود**؛ وضعیت در دیتابیس ذخیره و پنل هشدار می‌دهد. این رفتار به معنی ارسال پیامک نیست. گزارش فنی در `storage/logs/sms.log` نوشته می‌شود؛ دسترسی وب به این پوشه در Apache با `.htaccess` محدود شده است.

## ویرایش خدمات و قیمت‌ها

خدمات نمونه در `database/schema.sql` قرار دارند. پس از نصب می‌توانی در phpMyAdmin، جدول `services` را ویرایش کنی:

- `name`: نام خدمت
- `description`: توضیح کوتاه
- `duration_minutes`: مدت به دقیقه
- `price`: قیمت به تومان
- `is_active`: مقدار `1` برای نمایش و `0` برای غیرفعال‌کردن
- `sort_order`: ترتیب نمایش

هنگام ثبت هر نوبت، نام، قیمت و مدت خدمت در همان نوبت نیز ذخیره می‌شود تا ویرایش بعدی قیمت خدمات، اطلاعات نوبت‌های قبلی را تغییر ندهد.

## نکات پیش از انتشار عمومی

- الگوی شماره موبایل فعلی برای شماره ایران (`09xxxxxxxxx`) است. برای شماره کشورهای دیگر، تابع `valid_phone()` در `includes/bootstrap.php` را متناسب با کشور مقصد تغییر بده.
- پیش از انتشار سایت روی اینترنت، گذرواژه قوی برای MySQL و حساب مدیر تنظیم کن و سایت را فقط از طریق HTTPS ارائه بده.
- برای محیط واقعی، کلید API پیامک را در مخزن عمومی یا فایل‌های قابل‌دسترسی قرار نده؛ آن را در تنظیمات محیط سرور نگهداری کن.
- جلوگیری از تداخل رزرو با قفل روزانه MySQL پیاده‌سازی شده است. تمام رزروها باید از همین برنامه یا سامانه‌ای استفاده کنند که همان سازوکار قفل را رعایت می‌کند.
- قیمت‌ها و خدمات فایل SQL صرفاً نمونه‌اند؛ پیش از تحویل به آرایشگاه، نام خدمات، قیمت، ساعات کاری و متن پیامک را با کسب‌وکار هماهنگ کن.
- از دیتابیس به‌صورت منظم نسخه پشتیبان بگیر.

## ساختار فایل‌ها

```text
barber-booking/
├── index.php                  صفحه نوبت‌دهی مشتری
├── book.php                   اعتبارسنجی و ثبت امن نوبت
├── setup.php                  ایجاد اولین مدیر
├── app/config.php             تنظیمات اتصال و اطلاعات پروژه
├── includes/bootstrap.php     اتصال PDO، نشست، CSRF و توابع کمکی
├── includes/SmsService.php    اتصال پیامک
├── api/availability.php       API زمان‌های آزاد
├── admin/login.php            ورود مدیر
├── admin/index.php            داشبورد و مدیریت نوبت‌ها
├── admin/actions.php          تغییر وضعیت و ارسال پیامک
├── admin/logout.php           خروج امن
├── assets/css/style.css       طراحی صفحات
├── assets/js/app.js           تعاملات صفحه رزرو
├── assets/js/admin.js         تعاملات پنل
├── database/schema.sql        ساخت دیتابیس و خدمات نمونه
└── storage/logs/sms.log       گزارش‌های فنی پیامک (پس از ایجاد)
```
